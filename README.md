# Skill Quest

QR-friendly mobile web game for a Skill Development Club.

## Games
- 24 Hours: CEO
- Human vs Machine
- Digital Escape Room

## Publish free with GitHub Pages
1. Create a GitHub repository named `skill-quest`.
2. Upload `index.html`, `css/style.css`, and `js/app.js`.
3. Repository Settings → Pages.
4. Select `Deploy from a branch` → `main` → `/ (root)` → Save.
5. Open the generated `github.io` URL.
6. Generate a QR code from that URL.

No backend is required for this starter version. Scores are per game session/browser. A shared live leaderboard can be added later with a database/backend.
